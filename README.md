# Aesthetic Avenue Dental Clinic website

Deploy-ready static website for GitHub Pages.

## Structure

- `index.html` — site content, SEO metadata and schema
- `css/style.css` — responsive design and motion
- `js/script.js` — navigation, reviews, FAQ, treatment details and booking flow
- `assets/images/hero-dental.png` — supplied hero artwork

## Deploy on GitHub Pages

Upload everything inside this folder to the root of a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The appointment form opens a prefilled WhatsApp conversation. It intentionally does not store medical information or promise that the requested time is confirmed.
