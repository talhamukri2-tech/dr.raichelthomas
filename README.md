# Aesthetic Avenue Dental Clinic website

Premium static website for Dr. Raichel Thomas and Aesthetic Avenue Dental Clinic, Nerul. It is ready for GitHub Pages.

## Structure

- `index.html` — site content, SEO metadata and schema
- `css/style.css` — responsive visual system and Aesthetic Arch layout
- `js/script.js` — treatment navigator, reviews, FAQ, mobile menu and appointment request
- `assets/images/` — clinic campaign, doctor portrait, dental display and treatment results

## Deploy on GitHub Pages

Upload everything inside this folder to the root of a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The appointment form opens a pre-filled WhatsApp request. It does not store patient data on the website. Avoid collecting medical records or sensitive health information through the form.
